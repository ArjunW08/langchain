# langchain
langchain tutorials

## Intro
LangChain is a opensource framework for developing applications powered by large language model.

## Benifits 
1. Concept of chains
2. Model agnostic development
3. Complete ecosystem
4. Memory and state handling

## Applications 
1. Conversational ChatBots
2. AI Knowledge Assistants
3. AI Agents
4. Workflow Automation
5. Summarization/Research Helpers
